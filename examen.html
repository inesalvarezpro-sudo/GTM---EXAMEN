Examen · Google Tag Manager & GA4

Sujet d'examen

Vous êtes l'équipe data de Kop Store. Le site vient d'être mis en ligne sans aucun suivi. En 4 heures, vous allez installer GA4, suivre les éléments clés du site, faire remonter l'e-commerce et exploiter les données. Documents autorisés : vos notes et les pages de formation.

Avant de commencer 1. Installation 2. Tracking 3. E-commerce 4. Avancé Annexe

Avant de commencer 10 min

  1. Créez votre copie du site. Sur la page GitHub du dépôt modèle (lien donné en séance), cliquez sur Use this template → Create a new repository. Nom : examen-gtm-votrenom, visibilité Public.
  2. Publiez-le. Dans votre nouveau dépôt : Settings → Pages → Source Deploy from a branch, branche main, dossier / (root) → Save. Après 1 à 2 minutes, votre site est en ligne à l'adresse https://votre-pseudo.github.io/examen-gtm-votrenom/hello.html.
  3. Préparez votre navigateur : désactivez votre bloqueur de publicité sur votre site, et gardez la console ouverte (F12).
Le bouton { } dataLayer, en bas à gauche de chaque page, montre tout ce qui est poussé dans le dataLayer. Le lien « Réinitialiser la boutique », en pied de page, vide le panier et la commande.
Partie 1 · 30 min · 4 points

Installation de GA4 et GTM

1.1 — Créer la propriété GA4 1 pt

  • Créez une nouvelle propriété GA4 nommée « Kop Store Examen – Votre nom », fuseau horaire France, devise euro.
  • Créez-y un flux de données Web pour l'adresse de votre site. Notez son ID de mesure (G-…).
  • Question, à répondre en une phrase : quelle est la différence entre une propriété et un flux de données ?

1.2 — Installer Google Tag Manager 1,5 pt

  • Créez un nouveau conteneur GTM Web nommé « Kop Store Examen – Votre nom ».
  • Sur toutes les pages de la boutique : renseignez l'ID de votre conteneur dans le fichier gtm-install.js de votre dépôt.
  • Sur la page installation.html, qui n'utilise pas ce fichier : installez GTM à la main, en collant les deux codes officiels fournis par GTM au bon endroit.

1.3 — Brancher GA4 dans GTM 1 pt

  • Créez une variable Constante qui contient votre ID de mesure.
  • Créez la balise Google, qui utilise cette variable, déclenchée sur toutes les pages.
  • Vérifiez en mode Aperçu que la balise se déclenche sur hello.html et sur installation.html, et que votre visite apparaît dans le rapport Temps réel de GA4.

1.4 — Donner accès au correcteur 0,5 pt

  • Ajoutez votre formateur (adresse donnée en séance) en lecture sur votre conteneur GTM et sur votre propriété GA4.
  • Publiez une première version de votre conteneur, nommée « Partie 1 ».
